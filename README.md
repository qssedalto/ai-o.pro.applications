# AI-O Studio

原生 macOS 14+ 商城只读客户端（SwiftUI / Swift Package Manager）。商户凭证存于本机钥匙串；仅访问固定 HTTPS 站点，不读取 Cookie、不进行余额扣款。

## 构建

在 Mac 安装 Xcode Command Line Tools 后运行：

    swift test
    bash scripts/package.sh
    open "dist/AI-O Studio.app"

GitHub Actions 生成 ad-hoc 签名 ZIP，未进行 Apple 公证。CI 不读取商户密钥。

## 主要功能

- 经营概览：账户余额、分类统计、自动发货数量、最近同步状态。
- 商品中心：分类、搜索、封面、商品详情。
- 库存中心：目录低库存/缺货筛选，手动读取规格库存。
- 价格与利润：表头明确的会员价格表、实时总报价、分站零售价及参考毛利。
- 历史趋势：按商户隔离的本地查询快照，按商品、规格、数量、日期及指标筛选，图表选择与 CSV 导出。
- 账户设置：Keychain、连接测试、失败提示。

目录库存与规格库存口径不同；超大库存仅标记待确认。供应商库存/销量不视为本店资产。历史仅记录手动成功查询，不进行自动轮询。旧版未隔离的历史不自动迁移。商品说明禁用脚本和外部资源；封面仅接受已知 HTTPS CDN 的地址。多维 SKU 和预选卡尚未完整实现，已知 SKU 商品限制报价/库存操作。任何交易、自动采购和账户凭证交付均未实现。
